# Oracle AI

Oracle AI is a climate risk prediction and analytics platform for district-level forecasting using machine learning and explainability workflows.

## Structure

- Backend: FastAPI service for prediction, analytics, and district data APIs
- Frontend: React + TypeScript dashboard for exploring climate and risk insights
- Docs: Project documentation and implementation notes
- Scripts: Setup and orchestration helpers

## Getting started

1. Set up the backend environment.
2. Install frontend dependencies.
3. Start the backend and frontend apps.
4. Browse the dashboard at the local frontend URL.

For detailed setup instructions, see the project documentation in the docs folder and the backend README.
